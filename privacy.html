개인정보처리방침

예산 가계부 (운영: Axon Bridge) · 시행일 2026년 11월 13일

1. 가계부 데이터의 저장 위치

지출 기록, 예산, 계정, 자동 기록 항목 등 가계부의 모든 데이터는 사용자 본인의 구글 드라이브에 있는 스프레드시트에만 저장됩니다. 운영자는 이 데이터를 수집·보관·열람·제3자 제공하지 않습니다. 가족이 기록한 내용도 구매자의 스프레드시트에 바로 저장되며 운영자를 거치지 않습니다.

2. 운영자가 보관하는 정보

항목목적보관 기간
구매자와 등록된 가족의 구글 이메일 주소, 구매일, 만료일, 판매 메모사용 권한(라이선스) 확인사용 기간 동안. 삭제 요청 시 지체 없이 삭제
구매자 가계부 스프레드시트의 파일 ID가족이 같은 가계부에 연결하도록 안내위와 같음

운영자는 파일 ID로 가계부 내용을 열람할 권한이 없습니다(가계부는 구매자와 구매자가 공유한 가족에게만 공유됩니다).

3. 요청하는 구글 권한과 용도

권한용도
drive.file — 앱이 만들었거나 사용자가 선택한 파일 보기·수정가계부 시트 생성·기록, 등록된 가족에게 시트 공유, 가족의 가계부 연결
userinfo.email — 이메일 주소 보기사용 권한 확인
script.scriptapp — 사용자가 없을 때 실행매일 자동 기록 항목 기록

앱은 구글 사용자 데이터를 위 용도 외에 사용하지 않으며, 광고·판매·AI 학습 등에 사용하거나 제3자에게 전송하지 않습니다.

4. 삭제와 권한 해제

  • 가계부 데이터 삭제: 구글 드라이브에서 가계부 스프레드시트를 삭제하면 됩니다.
  • 앱 권한 해제: 구글 계정 → 보안 → 타사 앱 및 서비스에서 "예산 가계부"의 액세스를 삭제합니다.
  • 운영자 보관 정보(이메일 등) 삭제: 아래 이메일로 요청하면 지체 없이 삭제합니다.
